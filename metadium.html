운영과 모니터링

AWS에서 Linux 기반 블록체인 노드를 운영하고 업데이트하며, Datadog과 Zabbix로 상태를 확인할 수 있는 환경을 구성했습니다.

투입 인원3명
사용 기술AWS · Linux · Datadog · Zabbix

프로젝트와 담당 범위

씨피랩스의 핵심 사업인 Metadium 메인넷 인프라를 운영했습니다. AWS 기반 Linux 노드 관리, 업데이트와 모니터링 체계 구성을 맡았습니다.

노드 운영과 상태 확인

Linux 노드 운영·업데이트

두 도구를 함께 활용해 노드와 인프라 상태를 확인하는 모니터링 환경을 구성했습니다. 운영 중 상태 확인과 문제 파악에 사용할 수 있도록 관리했습니다.
