CASE STUDY 02

AWS 비용을
월 약 66% 줄인 과정

사용하지 않는 자원뿐 아니라 실행 환경과 약정까지 함께 검토했습니다.

범위회사 전체 AWS 비용
운영 환경2~3인 팀 / 멀티클라우드 300대 이상
핵심 기술Graviton · ECS · S3 · RI · Savings Plans
개선 범위실제로 수행한 조치개선 결과

개선 범위

씨피랩스에서 2~3인 팀으로 AWS를 비롯한 여러 클라우드에 걸친 300대 이상의 인프라를 운영했습니다. 그 과정에서 AWS 사용 현황을 분석하고 자원 구성과 과금 방식을 함께 개선했습니다.

이 비용은 대파 단일 서비스가 아닌 회사 전체 AWS 비용입니다.

실제로 수행한 조치

01 / 사용 자원

리소스 정리와 S3 이전

불필요한 리소스를 정리하고 정적 웹사이트를 S3로 이전했습니다.

02 / 데이터베이스

RDS를 Graviton으로 전환

모든 RDS를 Graviton 기반 인스턴스로 전환했습니다.

03 / 워크로드

EC2 온디맨드 기반 구성 변경

기존 EC2 온디맨드 기반 워크로드를 ECS 등 컨테이너·서버리스 환경으로 전환했습니다.

04 / 과금 방식

RI와 Savings Plans 전면 관리

예약 인스턴스와 Savings Plans 약정을 관리하며 리소스 구성뿐 아니라 약정에 따른 비용도 함께 검토했습니다.

개선 결과

66%월 AWS 총비용 약 66% 절감
개선 전
$65,000
개선 후
$22,000

월 비용은 근삿값입니다. 약 66%는 개선 전후 총액을 기준으로 계산했습니다.

월 약 6만 5천 달러였던 AWS 비용을 약 2만 2천 달러로 줄였습니다. 개별 조치별 절감액과 상세 비교 기간은 이 기록에서 별도로 제시하지 않습니다.
