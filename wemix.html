CASE STUDY 03

WEMIX / WEMIX.FI
서비스 인프라 구축

위메이드의 외주 의뢰로 진행한 프로젝트에서, 고객사와 요구사항을 조율하며 메인넷·DeFi 서비스의 실행 환경과 배포 구성을 맡았습니다.

기간 / 소속2023.06 – 2024.06 / 씨피랩스
투입 인원당사 2명
사용 기술Azure · Docker · Kubernetes · Argo CD · Datadog
프로젝트와 담당 범위실제로 수행한 작업고객사 협업

프로젝트와 담당 범위

WEMIX와 WEMIX.FI의 블록체인 메인넷 및 DeFi 서비스 인프라를 구축·운영했습니다. Docker 기반 메인넷 환경부터 Azure Kubernetes 클러스터, 자동 배포와 모니터링까지 담당했습니다.

실제로 수행한 작업

Docker 기반 메인넷 환경

블록체인 메인넷 네트워크를 Docker 기반으로 구축했습니다.

Azure Kubernetes 클러스터

Azure 기반 Kubernetes 클러스터를 설계하고 서비스 컨테이너가 실행될 환경을 구성했습니다.

Argo CD 기반 자동 배포

자동 배포 파이프라인을 기획하고 Argo CD를 적용했습니다.

Datadog 모니터링

메인넷과 서비스의 운영 상태를 확인하는 모니터링 환경을 구성하고 운영했습니다.

고객사 협업

외주 프로젝트의 인프라 담당자로서 고객사 요구사항을 조율하고 구축·운영 과정에서 협업했습니다. 당사 2명이 참여해 메인넷 실행 환경과 서비스 운영에 필요한 구성을 담당했습니다.
