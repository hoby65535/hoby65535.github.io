CASE STUDY 03

WEMIX / WEMIX.FI
인프라 구축·운영과 마이그레이션

위메이드 외주 프로젝트에서 노드 서버와 네트워크 구축, GitHub Actions 배포 자동화, 시스템 모니터링과 서버 운영을 담당했습니다.

기간 / 소속2023.06 – 2024.06 / 씨피랩스
담당노드·네트워크 구축 / 배포 자동화 / 모니터링·운영
사용 기술Azure · Docker · Docker Compose · Kubernetes · GitHub Actions · Helm · Argo CD · Datadog
프로젝트와 담당 범위사용 기술과 수행 범위Docker·Compose 기반 시스템 운영기존 시스템의 Kubernetes 마이그레이션GitHub Actions·Helm·Argo CDDatadog 수집과 알림 구성

프로젝트와 담당 범위

위메이드의 외주 의뢰로 WEMIX·WEMIX.FI·WEMIX Explorer 관련 인프라 작업을 수행했습니다. 노드 서버와 네트워크를 구축하고, 배포 자동화와 시스템 모니터링, 서버 운영을 담당했습니다.

Docker 기반으로 시스템을 구축·운영한 뒤 기존 환경을 Kubernetes로 마이그레이션했습니다. 배포에는 GitHub Actions와 Helm·Argo CD를 사용했고, Datadog으로 운영 상태를 확인했습니다.

사용 기술과 수행 범위

Docker·Compose 기반 시스템 운영

위메이드로 시스템을 이관하기 전에는 시스템 전체를 Docker 기반으로 관리했습니다. 실행 환경에 맞춰 Dockerfile을 직접 작성하고, Docker Compose로 컨테이너 구성을 관리했습니다.

Dockerfile 직접 작성

서비스 실행에 필요한 컨테이너 이미지를 구성하기 위해 Dockerfile을 작성했습니다.

Docker Compose 활용

Compose 파일로 컨테이너 실행 구성을 정의하고 Docker 기반 시스템을 운영했습니다.

기존 시스템의 Kubernetes 마이그레이션

기존 Docker 기반 시스템을 Kubernetes 실행 환경으로 옮기는 작업을 진행했습니다. Docker Compose 구성을 Kubernetes 리소스로 변환하는 도구를 활용하고, 필요한 매니페스트를 직접 작성·조정했습니다.

담당 범위는 기존 시스템의 Kubernetes 마이그레이션과 실행 리소스 구성이었습니다.

GitHub Actions·Helm·Argo CD

GitHub Actions로 배포 자동화를 구성했습니다. Kubernetes 배포 설정은 Helm 차트로 관리하고, Argo CD를 활용한 GitOps 자동화를 적용했습니다.

기술수행한 작업
GitHub Actions배포 워크플로 구성과 자동화
Helm차트 기반 배포 설정 관리
Argo CD · GitOpsGit 기반 배포 자동화 적용

Datadog 수집과 알림 구성

Datadog에서 인프라 지표, 컨테이너 상태, 로그, APM을 수집해 시스템과 서비스 상태를 확인했습니다. 수집한 정보를 바탕으로 운영에 필요한 모니터와 알림을 구성했습니다.

지표·로그·APM 수집

서버 리소스와 컨테이너 상태부터 로그·애플리케이션 성능 정보까지 수집해 모니터링했습니다.

리소스 모니터와 DB Slow Query 알림

리소스 상태를 확인하는 모니터와 DB Slow Query 등에 대한 알림을 구성하고 운영했습니다.
