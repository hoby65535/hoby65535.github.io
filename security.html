CASE STUDY 05

보안 인증 대응과
사내 보안 운영

가상자산 수탁 서비스 ‘마이키핀월렛’의 인증 대응에 참여하고, 기술적 보안 조치와 사내 보안 솔루션 운영을 함께 맡았습니다.

기간 / 소속2021.03 – 2026.05 / 씨피랩스
투입 인원정보보안팀 3명
사용 기술EDR · DLP · VPN · Linux · Windows
프로젝트와 담당 범위보안 업무 범위인증 심사 대응사내 보안 운영

프로젝트와 담당 범위

IT 엔지니어 및 정보보호 담당자로서 마이키핀월렛의 VASP 신고와 ISMS 인증 심사에 대응했습니다. 보안 정책 수립·이행과 서비스 운영 환경의 기술적 보안 조치를 담당했습니다.

보안 업무 범위

인증 심사 대응

가상자산사업자 신고 및 ISMS 인증 심사 대응 과정에 참여했습니다. 보안 정책을 수립·이행하고 운영 환경에 보안 요구사항을 반영해 2021년 인증 취득에 기여했습니다.

사내 보안 운영

EDR·DLP 운영

사내 EDR과 DLP를 운영하며 단말 보안 및 정보보호 업무를 수행했습니다.

서비스 운영과 보안 요구사항 반영

서비스 인프라 운영 업무와 함께 정보보호 담당 업무를 맡아, 인증 대응에 필요한 정책과 기술적 조치를 운영 환경에 반영했습니다.
